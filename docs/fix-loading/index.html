The list won't load

If the Proxy list shows an empty page, a spinner that never finishes, or an error, old saved data from a previous visit is the most common cause. The site normally detects this and resets its own data automatically, or shows a Reset saved data & reload button. If that didn't work, follow the steps below.

Quick fixes Chrome Edge Firefox Safari

Quick fixes

  1. Open the list's Settings and click Reset saved data (if the page loads far enough to show it).
  2. Reload using the proxy's own reload button, not only the browser's.
  3. Open the list in a private window (Ctrl+Shift+N in Chrome/Edge, Ctrl+Shift+P in Firefox, ⌘+Shift+N in Safari). If it works there, the problem is saved data, and the steps below will fix your normal window.
Using the list through a web proxy? Clear the data for the proxy's address (the one in your browser's address bar, for example proxy.example.com), not for github.io. Proxies keep each site's saved data under their own address. Clearing it also resets that proxy's own settings (such as its chosen transport or history).

Google Chrome (Windows, macOS, ChromeOS, Linux)

Option 1: from the address bar

  1. Open the site (or proxy) where the list isn't loading.
  2. Click the icon to the left of the address (the View site information / tune icon).
  3. Choose Site settings.
  4. Click Delete data and confirm.
  5. Close the tab, open it again, and load the list.

Option 2: from Chrome settings

  1. Go to chrome://settings/content/all.
  2. Search for the site's or proxy's address.
  3. Click the trash icon next to it and confirm.

Option 3: developer tools

  1. On the broken page, press F12 (or Ctrl+Shift+I, ⌘+Option+I on Mac).
  2. Open the Application tab, then Storage in the left sidebar.
  3. Click Clear site data, then reload.

On Android: tap ⋮ → Settings → Site settings → All sites, pick the address, and tap Delete / Clear & reset.

Microsoft Edge

Option 1: from the address bar

  1. Click the lock icon to the left of the address.
  2. Choose Cookies and site data, then Manage cookies and site data (or Permissions for this site).
  3. Delete the stored data for the site or proxy, then reload.

Option 2: from Edge settings

  1. Go to edge://settings/content/all (or edge://settings/siteData).
  2. Search for the site's or proxy's address.
  3. Click the trash icon (or Delete) and confirm.

Edge's developer tools work the same as Chrome's: F12 → Application → Storage → Clear site data.

Mozilla Firefox

Option 1: from the address bar

  1. Click the lock icon to the left of the address.
  2. Choose Clear cookies and site data….
  3. Click Remove, then reload.

Option 2: from Firefox settings

  1. Go to about:preferences#privacy.
  2. Under Cookies and Site Data, click Manage Data….
  3. Search for the site's or proxy's address, select it, click Remove Selected, then Save Changes.

On Android: tap ⋮ → Settings → Delete browsing data, or open the site, tap the lock icon, and choose Clear cookies and site data.

Safari

macOS

  1. In the menu bar, choose Safari → Settings… (or Preferences…).
  2. Open the Privacy tab and click Manage Website Data….
  3. Search for the site's or proxy's address, select it, click Remove, then Done.
  4. Reload the page.

iPhone and iPad

  1. Open the Settings app, then Apps → Safari (on older versions, just Safari).
  2. Tap Advanced → Website Data.
  3. Search for the site's or proxy's address, swipe left on it, and tap Delete.
  4. Reopen Safari and load the list.

Still not working?

  • School or work devices may block clearing site data. Try a private window or a different proxy from the list.
  • The proxy itself may be down or incompatible. Try another proxy or transport (for example, epoxy or libcurl instead of wisp-js).
  • Report it through the contribute page and include the proxy's address and any error message shown.
